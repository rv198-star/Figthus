# 构图模式与原创规则

## 顶层规则

先选认知动作，不画概念名词。

## 六宫格不是六个知识点

当交付模式是 `narrative-comic-6` 时，先读取 `narrative-comic.md`。六宫格的顶层单位不再是一张“认知锚点图”，而是一个会变化的判断：

```text
具体触发 → 暴露摩擦 → 重问问题 → 看见入口 → 做出取舍 → 落到新判断
```

每格必须和上一格有因果、反转、发现或行动上的变化。若六个想法可以任意交换位置，它们是清单，不是连环画；改回普通 shot list，或先重写叙事承诺。

连续性优先靠一个跨格视觉线索：重复出现但状态变化的角色、纸条、铅笔线、工具或问题卡。不要把同一个角色以同一站姿重复六遍。

## 默认先选物件，而不是先选角色

构图先经过一个“去拟人化测试”：如果去掉腿、眼睛和对白，仍然能看出动作、摩擦和后果，就用 restrained-object-vignette。优先画一个有磨损的破橡皮、擦痕、断线、灰屑、接触面或重新开出来的空白。

- restrained-object-vignette：1 个物件 + 1 个动作 + 1 个后果；主体约占 20%-45%，保留 55%-80% 的安静留白。
- trace-object：在物件上增加轻微倾斜、接触、短动作线或一点点残留痕迹；文字最多 1-2 个短词。
- character-led：只有当两种力量的互动不可替代时，才调用烂笔头与破橡皮的角色规则。

这会把“破橡皮”从一个固定站姿的说明角色，迁移成一个可以被观察、挤压、磨损和留下后果的视觉材料。

不要直接画：

- AI Agent
- Loop Engineering
- Prompt Engineering
- 反馈机制
- 评估系统
- 知识管理

要先抽取成：

- 第一版被推出去
- 证据被拖回来
- 假清楚被擦掉
- 失败被分类
- 死循环被闸门拦住
- 改动被放进不同槽位
- 好句子从废话里被擦出来
- 空白被重新开出来

## 基础结构类型

选择一种结构即可，不要混太多。

### 推出第一版

适合：开始、破局、草稿、把想法外化。

画法：烂笔头把第一条歪线推上纸带、路面、卡片或小机器；破橡皮可以在远处等着，或画面只留下擦痕预示下一步。

### 擦掉假清楚

适合：删除废话、去掉幻觉、复盘、校准。

画法：破橡皮擦掉看似完整但虚的线条、标题、路径或框架，露出更小但更真实的结构。

### 证据回流

适合：反馈、测试、Loop Engineering、外部结果、评价器。

画法：蓝色证据单从外部窗口、秤、闸门、邮筒或小机器里回来；破橡皮拿证据，烂笔头准备改下一笔。

### 停止规则

适合：避免死循环、预算、人工介入、失败边界。

画法：破橡皮守住停止闸、刹车杆、红色小门；烂笔头还想往前冲。

### 重启空白

适合：推翻重来、重新定义问题、删掉复杂方案。

画法：破橡皮擦出一块干净空地，烂笔头在空地边缘重新下第一笔。

### 并行修正

适合：拆问题、分支验证、两边同时改。

画法：破橡皮裂成两半分别擦两侧；烂笔头在中间接线、标注或重新画框。

### 失败分类

适合：把失败分为提示词问题、工具问题、目标问题、证据不足。

画法：失败纸团被放进几个低科技槽位；破橡皮称重或盖灰印，烂笔头写新的小标签。

## 原创隐喻生成法

每次都从当前文章重新发明隐喻，不能照搬旧图或角色设定图。

### 三步

1. 把抽象概念换成一个物理动作：写出、擦掉、裂开、堵住、回流、停住、重启、接上、分类、称重。
2. 把系统结构换成一个低科技物件：纸带、抽屉、旧机器、秤、邮筒、闸门、打孔器、压面机、晾衣绳、旧工位。
3. 选择出场角色：先做角色必要性判断。烂笔头负责生成痕迹，破橡皮负责擦改、校准、停止或裂开；两者可以同屏，也可以只出现更贴合当前动作的一个。

未出场的一方不能被彻底抹掉。用铅笔线、擦痕、灰屑、空白、断芯、证据单、裂缝或旧标注留下它的力量。

双角色同屏不是默认值。只有当两者分别承担不同动作，并且这组互动正好表达文章里的结构张力时才使用，例如：烂笔头推出第一版、破橡皮守停止闸；破橡皮拖回证据、烂笔头据此改下一笔。否则使用单角色，让另一方只以痕迹在场。

### 可用物件池

- 纸带、草稿纸、抽屉、旧机器、漏斗、秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪工位。
- 用时只选 1-2 个，不要堆满。

### 角色动作池

烂笔头：

- 写、划、戳、圈、拖、接、顶、推、标记、断芯。

破橡皮：

- 擦、压、堵、守、推回、开窗、裂开、分擦、清空、粘回。

动作要服务核心意思，不要为了怪而怪。

## 反复刻规则

不要复刻角色设定图里的正面、侧面、背面、动作分格。它们只用于校准外形。

不要默认复用上游小黑旧案例构图。`assets/legacy-xiaohei-examples/` 只用于历史来源和风格密度参考，不是 Figthus 构图库。

同类主题也要换新隐喻。例如“证据回流”不一定画循环箭头，可以画破橡皮从测试窗口拖回一张蓝色证据单；“重启”不一定画刷新按钮，可以画破橡皮擦出一块空地，烂笔头重新下笔。
