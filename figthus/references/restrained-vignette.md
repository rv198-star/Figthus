# 克制物件小品模式

## 这条迁移路径解决什么问题

Figthus 早期容易把每个抽象概念都放进 16:9 正文配图、中文批注和拟人化文具角色里。这样信息表达稳定，但会继续靠近上游“小黑”项目的文章配图语法。

restrained-object-vignette 是一条更安静的迁移路径：保留破橡皮的物质身份与“擦掉假清楚”的隐喻，但把它先当成一个有磨损的真实物件，而不是一个必须出场、必须有脸、必须做动作的角色。

## 视觉读法

Reading this as: an article-illustration / visual-IP system for thoughtful readers, with a quiet, dry, tactile and slightly absurd language, leaning toward a small editorial object vignette rather than a character explainer.

三个控制量：

- DESIGN_VARIANCE: 6。构图可以有一点不平衡和意外，但不靠复杂隐喻堆叠制造新奇。
- MOTION_INTENSITY: 2。动作只保留一个很小的物理变化，例如擦出一小块空白、让线条弯一下、留下几粒橡皮屑。
- VISUAL_DENSITY: 2。主体少、文字少、道具少；留白本身是构图的一部分。

## 具象性门槛

“克制”指减少装饰和解释，不是抽掉故事事实。处理故事、人物经历或生活文章时，画面至少保留两类可直接识别的事实锚点：

- 地点：教室、厨房、公交站、病房、工位、楼道等。
- 人物关系：同桌、母子、同事、陌生人、医生与病人等。
- 具体动作：递出半块橡皮、收走试卷、把伞推过去、关掉灶火等。
- 可见后果：改干净的错题、湿掉的半边肩膀、空下来的椅子、留下的饭盒等。

故事配图不得只剩线、方块、箭头、空白等抽象符号。读者应先看懂“发生了什么”，再感受到其中的隐喻。只有原文自身就是抽象观点、方法论或概念短句时，才优先使用纯物件隐喻。

## 三种模式

### 1. restrained-object-vignette（默认）

适用于单个概念、物件隐喻、破橡皮状态、轻量文章配图和视觉风格探索。

- 破橡皮以一个磨损的两色橡皮物件出现，不画腿、眼睛、嘴巴或手。
- 画面只保留一个物件、一个小动作和 0–2 个辅助痕迹。
- 主体占画面约 20–45%，留出 55–80% 的浅色空白。
- 默认 0 个文字；只有用户明确需要时才加 1–2 个极短手写词。
- 不使用流程箭头、节点、边框、标题或结构类型标签。
- 如果用于文章正文，保持用户要求的比例；独立风格图没有指定比例时可用 1:1。

### 2. trace-object

适用于需要一点 Figthus 情绪、但不希望重新回到“小黑式角色”的场景。

- 物件仍然没有腿和脸。
- 可以用一个很小的横线、缺口方向、倾斜、擦痕或运动线制造死板但有意志的感觉。
- 物件的“人格”来自磨损、姿态和后果，不来自表情或台词。
- 文字最多 1–2 个词，不要给物件写完整对白。

### 3. character-led

仅当文章锚点确实需要两种力量互相作用时使用，例如“烂笔头推出第一版，破橡皮守停止闸”。这才启用腿、眼睛、角色动作和双角色关系。

character-led 仍然遵守 ip-character.md 的身份锁定；它不是默认模式，也不能因为需要让画面“更有趣”就自动启用。

## 破橡皮的物件化规则

- 保留粉色左侧、灰白右侧、粉色外缘缺口、脏灰和不规则裂缝作为物质识别线索；但不要求正面站立。
- 可以使用侧面、三分之二侧面、俯视或只露出擦拭接触面的局部视角。
- 用真实的磨损、铅笔灰、擦屑、旧字印和缺口表达“使用过”，不要用眼睛和表情表达情绪。
- 轮廓采用深炭黑或石墨色的触感线条，粗细有 2–3:1 的自然变化；主轮廓可以在低信息处断开，不要封死成图标。
- 默认只保留粉灰两色中的低饱和关系；如果概念需要证据或状态，最多再加一种很淡的蓝灰或锈红。
- 不要把破橡皮画成完整、干净、光滑的新文具；也不要画成品牌产品渲染图。

## 构图配方

优先从下面四种里选一种：

1. 擦出一个诚实空白：一小块过度确定的石墨线被擦掉，留下比原线更可信的空白。
2. 让确定性弯一下：一条很直的线在橡皮边缘前轻轻弯曲或断开。
3. 物件压住后果：破橡皮压住一个错误、断点或重复痕迹，只留下少量碎屑。
4. 小物件遇到阻力：橡皮碰到一条线、一个纸角或一个小缺口，画面只展示接触瞬间。

不要把这四种配方画成固定模板；每次更换接触方向、物件位置、空白形状和痕迹长度。

## Prompt 禁区

restrained-object-vignette 中默认禁止：

- 小黑、吉祥物、可爱文具角色、人物化表情。
- 腿、手、眼睛、嘴巴、对白气泡、角色名牌。
- 16:9 正文信息图的固定左右分栏、流程箭头、完整矩形框和节点网格。
- 3–6 个解释性中文批注、左上角标题、结构类型名称。
- 大场景、桌面透视、真实光影、渐变、商业插画、精致矢量边缘。

## 迁移判断

如果一张图去掉腿和脸之后，动作、后果和隐喻仍然成立，就应优先使用 object-vignette。

如果去掉腿和脸之后只剩一个普通静物，说明它需要 trace-object 的姿态或一条痕迹；仍然不要立刻加回完整角色。

只有当去掉角色关系后，文章里的推进/阻止、写入/校准或生成/验收张力消失，才升级到 character-led。
